# Icon sources

Local brand artwork supplements the installed Simple Icons collection. These files are served locally; the site does not load an icon CDN.

- `aws.svg`: [Devicon / Amazon Web Services](https://github.com/devicons/devicon/blob/master/icons/amazonwebservices/amazonwebservices-original.svg)
- `sql-server.svg`: [Devicon / Microsoft SQL Server](https://github.com/devicons/devicon/blob/master/icons/microsoftsqlserver/microsoftsqlserver-original.svg)
- `csharp.svg`: [Devicon / C#](https://github.com/devicons/devicon/blob/master/icons/csharp/csharp-original.svg)
- `openai.svg`: [Simple Icons 14.0.0 / OpenAI](https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/openai.svg), CC0 collection.
